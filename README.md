# iRent 智馭車況管家

## 專案介紹

本專案以 iRent 共享汽車使用情境為出發點，探討如何結合人工智慧與影像辨識技術，協助辨識車輛狀況，並提供維修判斷與決策輔助的應用構想。

## 專案目標

- 探討 AI 影像辨識在共享汽車車況判別上的應用。
- 協助業者辨識車輛狀況，作為後續處理與維修決策的參考。
- 透過數位化資訊呈現，降低車主與服務業者之間的資訊落差。
